# Portafolio de servicios — Nancy Paola Zárate Rincón

Sitio web de una sola página para presentar un perfil académico y técnico con enfoque en epidemiología y salud pública. El proyecto fue preparado como ejercicio académico y puede publicarse mediante GitHub Pages.

## Contenido

- Perfil orientado a epidemiología y salud pública.
- Experiencia institucional en la Secretaría de Salud de Boyacá.
- Habilidades técnicas: vigilancia en salud pública, análisis epidemiológico, investigación aplicada, gestión de información, enfoque territorial y comunicación técnica.
- Servicios: asesoría técnica, análisis de indicadores e información, análisis de situación de salud, formulación de proyectos, apoyo a investigación e informes.
- Referencia a la publicación sobre disparidades de la mortalidad por infección respiratoria aguda en menores de cinco años en Colombia (2018–2023), con enlace a ResearchGate.

## Archivos

- `index.html`: página completa con estructura, estilos y comportamiento.

## Publicar con GitHub Pages

1. Crea un repositorio público en GitHub.
2. Sube `index.html` a la raíz del repositorio.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios. GitHub Pages generará la dirección pública del sitio.
